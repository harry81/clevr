# CHANNEL_COPY — 채널별 복붙 카피 모음

> 각 항목은 **(a) 타겟 → (b) 복붙 카피 전문 → (c) 게시 타이밍 → (d) 성공 판정** 순서.
> 모든 링크는 https://github.com/harry81/clevr/releases/latest 단일 정본. 가짜 버전 태그 금지.
> 톤: 완전 무료 · 회원가입 없음 · 평생 무료 · 데이터 로컬 소유.

## C1. GeekNews

**(a) 타겟** — 개발자·오픈소스 얼리어답터, 사이드 프로젝트 관심층.

**(b) 게시 카피 전문**

```
[자작] 10인 이하 제조업 공장을 위한 무료 오픈소스 ERP (Electron + 내장 SQLite)

부모님/지인 공장에서 매달 말일마다 거래처 30곳 청구서를 엑셀로 복사하던 걸 보고 만들었습니다.
목표는 하나였습니다. "설치 1분, 월말 청구 5초, 데이터는 내 PC에만."

- 완전 무료, 회원가입 없음, 평생 무료 (MIT)
- 서버 없음: 로컬 단일 DB(SQLite WAL), 인터넷 없이 동작
- 온보딩 1분: 회사명만 넣으면 시드 거래처 3곳(대양공업/한일금속/태성정밀)과 표준 단가표가 채워짐
- 원클릭 일괄 청구 + 입금 FIFO 정산 + 거래처 원장 A4 인쇄

과금·트라이얼·텔레메트리 없습니다. 데이터 인질도 안 잡습니다(엑셀 1초 백업).

Windows용 다운로드: https://github.com/harry81/clevr/releases/latest
```

**(c) 게시 타이밍** — Day 0 오전(릴리스 직후), 평일 10~11시.

**(d) 성공 판정** — 업보트 ≥ 30, 댓글 ≥ 10, 저장 ≥ 20. 24시간 내 5 미만이면 본문 첫 문단을 재작성.

## C2. 클리앙 개발한당

**(a) 타겟** — 국내 개발자·자작 프로그램 관심층.

**(b) 게시 카피 전문**

```
(자작) 공장 사장님 엑셀 야근 줄여드리려고 만든 오픈소스 ERP 공개합니다.

전자레인지 아니라 Electron입니다만(...) 10인 이하 제조업만 타겟으로 기능을 과감히 쳐냈습니다.
정밀가공/금형/판금 현장에서 실제로 쓰는 것만 남겼습니다.

- 설치 1분, 온보딩에서 시드 거래처 3곳 자동 주입
- 월말 거래처별 청구서 원클릭 일괄 생성(부가세 자동)
- 부분입금 FIFO 정산 → 미수잔액 실시간, 원장 A4 인쇄 하단에 무료 안내 1줄
- 100% 로컬(SQLite 단일 파일). 서버/계정/텔레메트리 0

무료 공개니까 한번 깔아보고 안 맞으면 엑셀로 내보내고 바로 지우셔도 됩니다.
다운로드: https://github.com/harry81/clevr/releases/latest

피드백 환영합니다. 특히 현장 실무 관점 지적이 큰 도움 됩니다.
```

**(c) 게시 타이밍** — Day 0~1 저녁(21~23시), 개발한당.

**(d) 성공 판정** — 댓글 ≥ 15, 24시간 조회 ≥ 500.

## C3. OKKY

**(a) 타겟** — 실무 개발자, 오픈소스 기여 검토자.

**(b) 게시 카피 전문**

```
[오픈소스 공개] 비개발자 사장님을 위한 로컬퍼스트 ERP — Electron + node:sqlite

만든 계기와 기술 선택을 공유합니다. "왜 클라우드가 아니라 로컬인가"가 핵심이었습니다.
세무/매출 데이터를 서버에 올리는 순간 영세 제조업 사장님은 도입을 거부합니다.
그래서 서버·계정·광고·텔레메트리를 전부 뺐고, SQLite 단일 파일 + 엑셀 내보내기로 락인을 없앴습니다.

기술 스택: Electron, Node 내장 node:sqlite(WAL), Vanilla JS(window.App), electron-builder.
온보딩 시드 거래처 3곳(대양공업/한일금속/태성정밀)이 첫 화면을 비우지 않게 합니다.

설치형/포터블 다운로드: https://github.com/harry81/clevr/releases/latest

기여·이슈 환영합니다. README의 CONTRIBUTING을 참고해 주세요.
```

**(c) 게시 타이밍** — Day 1~3 평일 낮.

**(d) 성공 판정** — 조회 ≥ 500, 스크랩 ≥ 10, 유효 이슈/PR ≥ 1.

## C5. 네이버 제조업 카페/밴드

**(a) 타겟** — 실수요 사장님·1인 총무/경리.

**(b) 게시 카피 전문**

```
[무료 배포] 제조업 거래처/청구서/미수금 엑셀 양식 + 5초 자동화 프로그램

공장 사장님들 월말마다 거래처 30곳 청구서 수작업으로 복사하시죠?
그 고생 덜어드리려고 무료로 만들었습니다. 회원가입도, 결제도 없습니다.

1) 무료 엑셀 양식 4종 (거래처 / 단가표 / 청구서 / 미수금)
   - 온보딩 시드와 동일한 거래처 3곳(대양공업·한일금속·태성정밀)으로 바로 연습 가능
2) 무료 오픈소스 프로그램 [SME-ERP] (Windows 실행파일)
   - 설치 1분, 클릭 한 번에 지난달 단가 그대로 청구서 자동 생성
   - 나눠 들어온 입금도 오래된 청구서부터 자동 차감 → 미수금 실시간
   - 장부는 오직 사장님 PC에만 저장 (인터넷 없이 동작)

설치 없이 바로 쓰는 포터블 버전도 있습니다.
무료 다운로드: https://github.com/harry81/clevr/releases/latest

광고·유료 결제 절대 없습니다. 쓰시다 불편하면 엑셀로 그대로 내보내서 떠나셔도 됩니다.
```

**(c) 게시 타이밍** — Day 3~14, 평일 오전(카페 활성 시간). 홍보 태그 자제, 정보 공유 톤.

**(d) 성공 판정** — 다운로드 ≥ 100, 댓글 ≥ 20, 파일럿 신청 ≥ 1.

## C6. 소공인센터 / 소공인 단톡방

**(a) 타겟** — 소공인 집적지구(문래/성수/반월/성서 등) 대표.

**(b) 게시 카피 전문 (단톡 공유용)**

```
사장님들, 월말 청구서 작업 도와드리는 무료 프로그램 공유합니다.

- 공장 PC에 설치(또는 무설치 실행) 1분
- 거래처별 단가표로 청구서 원클릭 일괄 생성 (부가세 자동)
- 나눠서 들어온 입금 자동 정산 → 미수금 장부 안 꼬임
- 무료·회원가입 없음·평생 무료, 데이터는 내 PC에만 저장

예시 거래처 3곳(대양공업·한일금속·태성정밀)으로 바로 연습됩니다.
받으실 곳: https://github.com/harry81/clevr/releases/latest

설치가 어려우시면 댓글이나 DM 주시면 도와드리겠습니다.
```

**(c) 게시 타이밍** — Day 5~20, 센터 공지 가능일/단톡 오전.

**(d) 성공 판정** — 공유 ≥ 10회, 설치 문의 ≥ 3건.

## C7. 세무사 / 기장 실무자 네트워크

**(a) 타겟** — 영세 제조업체 기장을 맡는 세무사 사무실 담당자.

**(b) 게시 카피 전문**

```
[실무자용] 거래처 사장님 장부 정리 시간 줄여주는 무료 도구 공유

매달 말 거래처 사장님 엑셀 미수금과 통장 내역이 안 맞아 대조하시던 분들께.

- 사장님 PC에만 저장되는 로컬 프로그램 (서버 업로드 없음)
- 거래처 원장 A4/엑셀 정리 → 기장 자료로 그대로 활용
- 부분입금 FIFO 정산으로 차인지급잔액이 흔들리지 않음
- 예시 거래처 3곳(대양공업·한일금속·태성정밀)으로 바로 시연 가능

사장님들께 알려주시면 무료로 설치돼서, 넘어오는 자료가 깔끔해집니다.
무료 배포: https://github.com/harry81/clevr/releases/latest

기장 실무 관점의 개선 요청은 이슈로 남겨주시면 반영하겠습니다.
```

**(c) 게시 타이밍** — Day 7~21, 업무시간. 개인 네트워크 우선.

**(d) 성공 판정** — 파일럿 소개 ≥ 3건, 실무 피드백 ≥ 2건.

**(b) 배포 카피 전문 (인쇄물 하단 1줄 고정)**

```
본 문서는 10인 이하 소규모 제조업을 위한 100% 무료·회원가입 없는 오픈소스 ERP [SME-ERP]로 작성되었습니다 · 데이터는 내 PC에만 저장됩니다 · 무료 다운로드: https://github.com/harry81/clevr/releases/latest
```
