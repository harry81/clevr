회사명만 넣으면 끝, 1분 온보딩

10인 이하 제조업 사장님을 위한 무료 오픈소스 ERP. 설치 1분, 월말 청구서 5초, 거래처 원장은 카톡으로 바로 보냅니다.

설치형 다운로드 (.exe) 무설치 포터블 (.exe)

평생 무료 · 회원가입 없음 · 데이터는 내 PC에만

안전 확인: 설치형 SHA256 · 포터블 SHA256 · 버전 0.2.2

써보면 바로 느껴지는 3가지

어려운 회계 용어 없이, 하던 일만 훨씬 빠르게.

엑셀 복붙으로 거래처 3초 등록

엑셀에 정리해 둔 거래처 목록을 그대로 붙여넣으면 한 번에 등록됩니다. 사업자번호가 겹치는 곳은 알아서 건너뜁니다.

월말 청구서 5초 발행

버튼 한 번이면 등록된 거래처의 이번 달 청구서가 한꺼번에 만들어집니다. 부가세 계산은 자동입니다.

거래처 원장 카톡 전송

거래처별 미수금 요약을 이미지로 복사해 카톡에 그대로 붙여넣습니다. “얼마 남았소?” 전화가 줄어듭니다.

처음 실행할 때 파란 경고창이 떠도 안심하세요

코드 서명이 없는 무료 오픈소스라 Windows가 처음 한 번 경고를 띄울 수 있습니다. 악성코드가 아닙니다.

  1. 경고창에서 [추가 정보] 글씨를 클릭합니다.
  2. 오른쪽 아래에 나타나는 [실행] 버튼을 누릅니다.
  3. 내려받은 파일의 SHA256 값이 위 다운로드에 첨부된 .sha256과 같은지 확인합니다.

Windows PowerShell에서 Get-FileHash .\SME-ERP-Setup-0.2.2.exe -Algorithm SHA256 실행 후 값을 대조하세요. 자세한 안내는 SmartScreen FAQ를 참고하세요.

데이터는 내 컴퓨터에만, 소스는 모두에게 열려 있습니다

  • 100% 로컬 저장 — 거래처·청구·입금 장부는 사장님 PC 안에만 저장되고, 인터넷이 끊겨도 작동합니다.
  • 회원가입·서버 없음 — 계정을 만들 필요도, 데이터를 맡길 서버도 없습니다.
  • MIT 라이선스 — 누구나 무료로 쓰고, 소스를 확인하고, 필요하면 직접 고칠 수 있습니다.
  • 언제든 엑셀로 백업 — 데이터를 붙잡지 않습니다. 마음에 안 들면 그대로 내보내고 떠나셔도 됩니다.

입력한 비밀번호는 안전한 방식으로 잠겨 있고, 남에게 보이지 않습니다.
