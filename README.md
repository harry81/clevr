# 지점관리프로그램 — clevr 단일 기준 (branch-erp → clevr 통합)

> **단일 기준**: `clevr/`가 정본, `branches/branch-erp`는 레거시 읽기전용 — 모든 작업은 `clevr/` 기준으로만 수행하며 `clevr/docs`가 정본 문서이다.

DAWIN을 대체할 지점 설치형 프로그램의 실전 개발 시작점입니다.
기준정보(고객관리) 모듈까지는 등록/조회/삭제가 실제로 동작합니다.
나머지 메뉴는 클릭하면 "다음 개발 단계" 안내만 뜨는 자리표시자 상태입니다.

## 1. 처음 실행하는 방법 (지점 PC가 아니라 개발용 PC에서)

1. Node.js 설치 (https://nodejs.org, LTS 버전)
2. 이 폴더를 압축 해제한 뒤, 폴더 안에서 아래 명령 실행

```bash
npm install
npm start
```

3. 뜨는 로그인 화면에서 데모 계정으로 로그인
   - 지점코드: B1 / 아이디: b1acc / 비밀번호: 1234 (지점 계정)
   - 지점코드: HQ / 아이디: admin / 비밀번호: 1234 (본사 계정, 추후 통합조회 권한)

4. 좌측 "기준정보 > 고객관리"를 눌러 거래처를 등록/삭제해보면
   데이터가 실제로 저장되는 것을 확인할 수 있습니다.
   (지금은 내 PC의 `~/.branch-erp-data.json` 파일에 임시 저장됩니다.
   서버 관리자가 사내 DB를 구축하면 `db/localStore.js`만 실제 DB 연동
   코드로 교체하면 되도록 설계했습니다.)

## 2. 설치파일(.exe)로 만들어보는 방법

```bash
npm install --save-dev electron-builder
npm run build:win
```

`dist` 폴더 안에 설치파일이 생성됩니다. 지점 PC에는 이 설치파일을
배포하면 됩니다.

## 3. 다음 개발 순서 (기획서 6장과 동일)

1. ✅ 기준정보 — 전체 완료 (통합코드등록, 고객관리, 고객조회, 회사정보 등록)
2. ✅ 고지서관리 — 전체 완료 (일괄등록, 수정, 수정(일괄), 위험성/유해물질 등록, 미납관리, 발행현황)
3. ✅ 수금관리 — 전체 완료 (수금등록, 수금현황, 미수금현황, 거래처원장)
4. ✅ 출력관리 — 전체 완료 (고지서 발행, 세금계산서 출력, 미납고지서 출력, 봉투 출력, 계산서 등록/출력)
5. ✅ 교육관리 — 전체 완료 (교육고객관리, 년도별교육관리, 사업장별교육자관리, 교육출력관리(수료증), 교육비/계산서/미참석자관리, 교육현황관리, 교육자료 UPLOAD)
6. ✅ 기타관리 — 전체 완료 (사용자관리, 프로그램 관리)

## 남은 작업 (원본 메뉴 트리 밖의 것)
7. 서버 DB 연동 (localStore.js → 실제 DB 드라이버로 교체)
8. 본사 통합조회 (지점 데이터 통합 뷰)
9. Electron 패키징/배포 자동화
10. 세부 검증: 인쇄 양식 실사용 확인, 원본 캡처 대조를 통한 미세 UI 조정

## 4. 폴더 구조

```
branch-erp/
├── package.json
├── main.js          # Electron 메인 프로세스, DB 연동 지점
├── preload.js        # 렌더러 <-> 메인 안전한 통신 다리
├── db/
│   └── localStore.js # 임시 로컬 저장소 (나중에 실제 DB로 교체)
└── renderer/
    └── index.html     # 로그인 + MenuList 화면 + 고객관리 화면
```
