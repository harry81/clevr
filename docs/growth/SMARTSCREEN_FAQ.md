# SMARTSCREEN_FAQ — Windows 경고/백신 오탐 대응 FAQ

> **링크 정본**: https://github.com/harry81/clevr/releases/latest
> **요지**: 코드 서명이 없는 무료 오픈소스라 처음 실행 시 Windows가 경고를 띄울 수 있습니다.
> 악성코드가 아니라 **평판(reputation) 부족**이 원인이며, 아래 순서로 안전하게 실행할 수 있습니다.

---

## Q1. "Windows의 PC 보호" 창이 떠요.

코드 서명 인증서가 없는 실행파일은 처음 배포될 때 SmartScreen 평판이 쌓이기 전까지 경고가 뜹니다.
다음 순서로 실행하세요.

1. 경고창에서 **[추가 정보]** 를 클릭합니다.
2. 오른쪽 아래에 나타나는 **[실행]** 버튼을 누릅니다.

![경고 예시] 추가 정보 → 실행

## Q2. 다운로드한 파일이 진짜인지 어떻게 확인하나요?

릴리스에 첨부된 **SHA256 체크섬 파일**(`*.sha256`)과 대조합니다.

**PowerShell:**
```powershell
Get-FileHash .\SME-ERP-Setup-0.1.0.exe -Algorithm SHA256
```

출력된 해시가 릴리스의 `.sha256` 값과 **완전히 같으면** 정품입니다. 다르면 다운로드를 폐기하고
공식 릴리스(https://github.com/harry81/clevr/releases/latest)에서 다시 받으세요.

## Q3. 백신이 바이러스로 잡아요.

코드 서명이 없으면 일부 백신이 새 실행파일을 평판 기반으로 잡을 수 있습니다.
아래를 순서대로 확인하세요.

1. SHA256이 릴리스 체크섬과 일치하는지 확인(Q2).
2. 백신 예외(제외) 목록에 프로그램 폴더를 등록합니다.
3. 그래도 의심되면 [VirusTotal](https://www.virustotal.com/)에 파일을 올려 결과를 확인합니다.
4. 오탐으로 판단되면 사용 중인 백신사 **오탐 신고**에 파일과 SHA256, 릴리스 URL을 제출해 주세요.

## Q4. 데이터가 외부로 나가나요?

아닙니다. SME-ERP는 **로컬퍼스트**입니다.

- 서버·회원가입·텔레메트리 없음.
- 모든 장부는 사장님 PC의 `%LOCALAPPDATA%\SME-ERP\data\mycompany.db` 한 파일에만 저장.
- 인터넷이 끊겨도 동작합니다.

## Q5. 안심하고 쓰려면?

- 공식 릴리스 링크(https://github.com/harry81/clevr/releases/latest)에서만 받으세요.
- SHA256을 확인하세요(Q2).
- 데이터는 [전체 엑셀 내보내기]로 언제든 백업할 수 있습니다(데이터 인질 없음).
- 소스코드는 저장소에서 직접 확인·빌드할 수 있습니다(MIT).

## Q6. 코드 서명은 언제 되나요?

오픈소스 무료 프로젝트라 유료 코드 서명 인증서는 아직 없습니다. 서명 적용 시 릴리스 노트로 안내합니다.
그때까지는 SHA256 대조와 평판 축적으로 신뢰를 쌓습니다.
