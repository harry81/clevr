# WATERMARK_SPEC — 제품 내장형 바이럴(인쇄물 마이크로 푸터)

> **Task**: T06 · **상태**: 최소 구현 완료(워터마크 1종) · **버전**: package.json `0.1.0` 기준
> **범위**: 원장/청구 **인쇄물(PDF/출력)** 하단 1줄. 화면 UI·앱 실행에는 노출하지 않는다.

---

## 1. 목적

가공·제조업은 1·2·3차 협력업체가 거미줄처럼 얽혀 있다. A업체가 B업체로 원장 PDF를 보낼 때마다
하단 1줄이 자연스럽게 B업체 사장님에게 노출되어, **CAC 0원의 B2B 네트워크 획득 루프**를 만든다.

- 전환 트리거: 거래처가 원장/청구서를 카톡·팩스로 받아보고 "이 양식 뭐지?" → 다운로드 페이지 유입.
- 신뢰 톤: **완전 무료 · 회원가입 없음 · 평생 무료 · 데이터 로컬 소유**.

## 2. 구현 위치 (단일 소스)

| 항목 | 경로 |
|:---|:---|
| 인쇄물 빌더 | `renderer/js/views/ledger.js` — `printDoc(view)` |
| 푸터 문자열 | 같은 파일 `watermarkFooter()` |
| 테스트 | `tests/unit/renderer/watermark.test.js` |

- `printDoc`은 인쇄 HTML 전체를 만드는 순수 함수로 노출되어 `node:vm`으로 단위 검증한다.
- `render()`의 [원장 인쇄(A4)] 버튼이 `printDoc(view)`을 호출 → `print/html` IPC → PDF 저장.

## 3. 푸터 문안 (1줄 고정)

```
본 문서는 10인 이하 소규모 제조업을 위한 100% 무료·회원가입 없는 오픈소스 ERP [SME-ERP]로 작성되었습니다 · 데이터는 내 PC에만 저장됩니다 · 무료 다운로드: https://github.com/harry81/clevr/releases/latest
```

- 위치: 표(`</table>`) 직후, `<body>` 종료 직전.
- 스타일: `.sme-print-footer { margin-top:10px; font-size:10px; color:#666; text-align:right }`.
- **1줄 원칙**: 문안·링크를 늘리지 않는다. 인쇄 여백을 훼손하지 않는다.

## 4. 제약

- 외부 라이브러리·CDN·`require()` **0건** (오프라인 로컬퍼스트 유지).
- 미소유 도메인 금지. 링크는 `releases/latest`로 통일.
- 가짜 버전 태그 표기 금지 — 실제 릴리스 태그만 노출한다.
- 개인정보·거래 데이터는 푸터에 넣지 않는다.
