## 2. SmartScreen / 백신 오탐 대응 절차

### 2.1 원인

- 코드 서명(유료 인증서) 미적용 실행파일은 평판이 쌓이기 전까지 Windows SmartScreen·일부 백신이
  "알 수 없는 앱"으로 차단/경고할 수 있다. **악성코드가 아니라 평판 부족**이 원인이다.

### 2.2 사전 예방 (릴리스 시)

1. 릴리스에 **SHA256 체크섬 파일**(`*.sha256`)을 첨부한다(`.github/workflows/release.yml`).
2. README·`SMARTSCREEN_FAQ.md`에 "추가 정보 → 실행" 안내를 넣는다.
3. 가능하면 릴리스 산출물을 VirusTotal에 업로드하고 결과 링크를 FAQ에 남긴다.

### 2.3 대응 흐름 (문의 접수 시)

```
[문의] "설치가 막혀요 / 바이러스래요"
   │
   ├─ 1. SHA256 대조 안내: 다운로드 파일 해시가 릴리스 체크섬과 일치하는지 확인
   ├─ 2. SmartScreen: [추가 정보] → [실행] 절차 안내 (README 2단계)
   ├─ 3. 백신 격리: 예외 등록 또는 "평판 부족" 설명 + VirusTotal 링크 제공
   ├─ 4. 오탐 신고: 해당 백신사 오탐 신고 폼 제출 (파일·해시·릴리스 URL)
   └─ 5. 재현/증상 기록 → 필요 시 README/FAQ 보강
```

### 2.4 응대 스크립트 (복붙)

```
안녕하세요. 코드 서명이 없는 무료 오픈소스라 처음 실행 시 Windows가 경고를 띄울 수 있습니다.
악성코드가 아니며, 다음 순서로 실행하시면 됩니다.
1) 경고창의 [추가 정보] 클릭 → [실행]
2) 다운로드 파일의 SHA256이 릴리스에 첨부된 체크섬과 일치하는지 확인
3) 그래도 백신이 잡으면 예외 등록 후 실행
불편을 드려 죄송합니다. 릴리스: https://github.com/harry81/clevr/releases/latest
```

## 3. 파일럿 동의서 템플릿

> 파일럿 참여 전 취득. 서명/구두 동의 후 파일 보관. **익명 옵션**을 반드시 제시한다.

```
SME-ERP 파일럿 참여 동의서 (v0.1)

1. 목적
   - 무료 오픈소스 ERP(SME-ERP)의 실제 사용성 개선을 위한 파일럿 테스트

2. 수집 항목
   - (선택) 업종, 종업원 규모, 월 청구 거래처 수
   - 사용 피드백(불편점/개선 요청)
   - ※ 프로그램은 어떤 데이터도 자동 전송하지 않습니다. 실제 장부 데이터는 수집하지 않습니다.

3. 활용 범위
   - 제품 개선 및 사례 작성
   - 사례 공개 시 아래 중 하나를 선택합니다.
     [ ] 실명/상호 공개   [ ] 익명(예: "경남 소재 정밀가공 A사")   [ ] 비공개

4. 보관·파기
   - 동의 철회 시 수집한 피드백/사례를 즉시 삭제합니다.

5. 자발성
   - 참여는 자발적이며, 언제든 중단할 수 있습니다. 코어 기능은 영구 무료입니다.

동의자: ______________   상호(선택): ______________   일자: ____-__-__
익명 공개 동의: [ ] 예  [ ] 아니오
```
