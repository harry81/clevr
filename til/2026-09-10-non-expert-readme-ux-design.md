# TIL — 비전문가(50~60대 공장장/경리) README UX 설계

## 1. 독자를 고정하면 구조가 정해진다

- 페르소나: 10인 미만 제조업 사장·경리, 엑셀/수기장부는 가능하나
  Git·Node·터미널 개념은 전무. 핵심 질문은 하나 —
  "지금 당장 다운로드해서 내 컴퓨터에 깔고 쓸 수 있는가?"
- 이 질문에 답하는 순서가 곧 정보구조(IA)가 됐다:
  다운로드 버튼(최상단) → 3대 가치 → 3단계 설치 → 안심 선언 →
  개발자 가이드는 `<details>` 접기. 기술 스택·테스트는 일반 독자에게
  인지 장벽이므로 기본 접힘 처리로 원천 격리했다.

## 2. 다운로드 Above-the-fold: 첫 화면에서 이탈을 막는다

- 기존 README는 'Releases에서 내려받으세요'라는 텍스트 한 줄이 전부라
  다운로드 페이지를 찾을 수 없는 구조였다.
- 개편안은 가치제안 바로 아래에 설치형/포터블 shields 뱃지 2종 배치.
  URL은 `harry81/clevr/releases/latest`로 remote와 일치 확인済 —
  공개·산출물 존재 확정은 릴리스 게이트로 위임하고 문구는
  '릴리스 페이지에서 최신 파일'로 과장 없이 적었다.

## 3. SmartScreen: 이탈률 90% 지점을 2클릭 안내로 푼다

- 코드 서명 없는 무료 프로그램의 파란 경고창("Windows의 PC 보호")은
  일반 사용자가 바이러스로 오인하고 설치를 포기하는 최대 이탈 지점.
- 대응: 빨간 경고 블록 + 실제 Defender 문구 ASCII 모사 +
  `[추가 정보] → [실행]` 2단계 숫자 설명.
- 원인 문구는 "오픈소스 특성상" 같은 막연한 표현이 아니라
  "코드 서명이 없는 무료 프로그램이라 발생하는 정상 알림"으로 정밀화 —
  원인을 알면 안심하고, 모르면 삭제한다.

## 4. Local-First는 신뢰 마케팅이다

- "클라우드에 세무 데이터가 올라가면 어쩌나"가 사장님들의 실제 불안.
  대응 서술 3점: 내 PC(`내 컴퓨터`)에만 저장·외부 미전송·오프라인 동작,
  `scrypt` 잠금, 재설치해도 `mycompany.db` 보존.
- 정확한 경로는 인용하지 않았다 — `%LOCALAPPDATA%` 표기가 실제
  (`%APPDATA%`)와 달랐던 전례가 있어, 경로 대신 장소를 약속했다.

## 5. 스크린샷 수급: E2E 캡처를 공개 에셋으로 승격

- To-Be가 참조한 `docs/screens/`는 gitignore 처리라 공개 리포에 안 탄다.
  `assets/screens/` 신규 공개 경로를 만들고 E2E 캡처 2건
  (대시보드·온보딩 3단계, 각 1279×799 PNG)을 배치해 참조를 교체.
- 별도 촬영 세션 없이 검증済 캡처를 재활용 — 실제 앱 화면이라
  목업과 달리 출시물과 어긋날 염려가 없다.

## 6. Portable 정합: 빌드 산출물과 문서의 1글자 계약

- 전자빌더 portable 산출물은 단일 `.exe`인데 초안은 `.zip` 표기였다.
  설치 전에 깨진 정보를 배포하는 셈이라 블로커로 지정,
  '무설치 실행파일 (.exe)' + `SME-ERP-Portable-x.x.x.exe`로 교정.
- 교훈: 문서의 파일 확장자 하나도 빌드 설정과의 계약이다.
  `artifactName`과 README 표기는 릴리스마다 대조한다.
