# Today I Learned: 1인 소상공인·학원 친화적 UX 도메인 전환 및 번호 정규화 가드

- **날짜**: 2026-10-07
- **주제**: B2B ERP 도메인에서 1인 교육·용역 소상공인 도메인으로의 전면 전환 (청구도우미 리브랜딩)
- **작성자**: PM (agy) with Herdr Team (cvr-planner, cvr-worker, cvr-reviewer)

## 1. 배경 및 문제 의식
초기 SME-ERP는 "10인 이하 소규모 제조업"을 타겟으로 설계되어 다음과 같은 제약과 용어 불일치가 존재했습니다:
- **필수값 강제**: `사업자등록번호(000-00-00000)`가 필수여서, 학생/학부모/개인 회원 관리가 불가능함.
- **제조업 중심 용어**: `물품/단가`, `거래처`, `거래처별 거래 원장`, `차인지급잔액` 등 학원/교습소/도장 원장님에게 극심한 인지 부조화를 유발.
- **세무 부가세 강제**: 부가세 10% 자동 부과로 인해, 부가가치세법상 면세 교육용역 사업자(학원/교습소 등)가 사용하기 부적합함.
- **워터마크 불일치**: 카카오톡/영수증 출력물에 "소규모 제조업용 오픈소스 ERP"가 노출되어 학부모 전송 시 신뢰도 저하.

## 2. 핵심 이론 및 아키텍처 개선

### 2.1 도메인 모델 전환 (Terminology & Model Alignment)
- `상호 *` ➔ `이름 / 상호 *`
- `사업자등록번호 *` ➔ `연락처 / 식별번호 (선택)`
- `품목/단가` ➔ `청구 항목 / 금액 (수강료·회비)`
- `거래처별 거래 원장` ➔ `납부 명세서 / 영수증`
- `차인지급잔액` ➔ `남은 미납액`

### 2.2 하이픈 정규화의 엣지 케이스 (Edge Case in Normalization)
- **초기 구현의 문제**: 숫자가 10자리인 경우 무조건 사업자번호(`\d{3}-\d{2}-\d{5}`)로 변환하도록 구현함.
  - 이로 인해 서울 지역번호가 포함된 유선전화번호(`02-1234-5678`)가 `021-23-45678`로 오변환되어 데이터가 훼손되고 중복 검사 오탐이 발생함.
- **보완 패턴**:
  ```javascript
  // 하이픈 없는 순수 10자리 숫자이면서 국내 전화 대역(0으로 시작)이 아닌 경우만 사업자번호로 하이픈화
  if (/^\d{10}$/.test(trimmed) && !trimmed.startsWith('0')) {
    return `${trimmed.slice(0, 3)}-${trimmed.slice(3, 5)}-${trimmed.slice(5)}`;
  }
  return trimmed; // 02-xxx-xxxx, 010-xxxx-xxxx 등 일반 연락처는 원문 100% 보존
  ```

### 2.3 교육용역 면세(VAT 0%) 지원
- 전자세금계산서/청구서 발행 엔진에서 `isTaxExempt` 플래그를 도입.
- 면세 적용 시 `vatAmount = 0` 및 원장 테이블 반영을 통해 면세사업자용 영수증/청구서 정합성 보장.
